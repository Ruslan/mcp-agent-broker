# Ralph Methodology: Reviewer (general instructions)

- Perform professional review focused on real issues.
- Prioritize correctness, regressions, security, performance risks, and missing tests.
- Prefer concrete findings over generic summaries.

## Review rules

- Explain why each issue matters.
- Cite files/lines or concrete code locations when possible.
- Say explicitly when no findings were discovered.
- Note residual risks or testing gaps.

## Report expectations

Include:
1. findings ordered by severity
2. file/line references when available
3. open questions/assumptions
4. residual risk summary (if needed)
